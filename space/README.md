# Human Corpus MCP

A free public MCP server of verifiably human-written sentences: English Wikipedia as of
2022-03-01 (before ChatGPT) and Project Gutenberg public-domain books.

Connect: `claude mcp add --transport http human-corpus https://timourxyz-human-corpus.hf.space/mcp`

Source: https://github.com/timkosters/human-corpus · Index: https://huggingface.co/datasets/timourxyz/human-corpus
